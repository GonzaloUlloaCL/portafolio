## Lo que se repite en todas las etapas

- **Partir del proceso real, no de la herramienta.** Primero entender cómo se trabaja; después decidir qué se automatiza.
- **La IA interpreta; lo crítico lo resuelve código que se puede auditar.** En el bot de Patata el modelo entiende el
  pedido, pero el precio lo calcula el código contra el menú.
- **Verificar el efecto, no el aviso de "listo".** Cada sistema trae su prueba: banco de pruebas del bot, linter de la
  red, auditoría de los recorridos 3D y control de cada CV.
